# Changelog

## 0.2.0

- Added 30, 60, and 120 minute expedition planning.
- Added open-ended expedition mode.
- Added value-aware route scoring using travel time, useful attempt time, and collection opportunity.
- Added a "Why?" panel with planner reasoning.
- Added dynamic rerouting after collection or skip.
- Tightened several Timeless Isle source coordinates.
- Preserved native Blizzard waypoint and SuperTracking behavior.

## 0.1.0

- Initial Timeless Isle vertical slice.
- Added mount and battle-pet ownership scanning.
- Added missing-collection filtering.
- Added simple route generation.
- Added native waypointing and SuperTracking.
- Added compact next-stop tracker.
- Added automatic advance after collection changes.
